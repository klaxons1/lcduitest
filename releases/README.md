# Releases

Собранные MIDlet-сьюты, закоммиченные вручную (`deployed/` игнорируется git).

| Версия | Что внутри | Файлы |
|--------|------------|-------|
| lotus-0.0.13 | Lotus LOT8, то же видео: окружение — сетка 48×64, два треугольника на клетку, 16 цветов, палитра пересчитывается на каждый кадр (k-means; ключевой кадр каждые 25 кадров хранится целиком, остальные — дельтой к предыдущей палитре; индексы треугольников читаются из буфера кадра); гистерезис индексов 8; люди — мелкие треугольники до 4 px по ручной разметке, 64 цвета (k-means, взвешенный по площади); экран 240×320; MIDI на фоне. Вес выше 0.0.12 примерно на 19% (палитра на кадр). Классы препроверены CLDC-препроверщиком (`tools/fetch_j2me_tools.sh`), декодер проверен на CLDC KVM (`tools/kvm/check_film.sh`, checksum совпадает с десктопом) | `lotus-0.0.13/lcduitest.jar`, `lotus-0.0.13/lcduitest.jad` |

Предыдущие сборки (0.0.2 туннель, 0.0.3 сетка с полями, 0.0.4 статичная треугольная сетка, 0.0.5 квадродерево на весь кадр, 0.0.6 полигональный фон LOT5, 0.0.7 PNG-фон LOT6, 0.0.8 сетка 30×40 LOT7, 0.0.9 сетка 48×64 без препроверки, 0.0.10 препроверенная сборка с median cut, 0.0.11 k-means без гистерезиса, 0.0.12 LOT7) удалены, их можно посмотреть в истории git.

Установка на телефон: открыть `lcduitest.jad`. `MIDlet-Jar-URL` относительный, поэтому JAD и JAR
должны лежать в одной папке.
Пересборка: `./build.sh` в корне репозитория.
