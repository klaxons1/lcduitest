Предыдущие сборки (0.0.2 туннель, 0.0.3 сетка с полями, 0.0.4 статичная треугольная сетка, 0.0.5 квадродерево на весь кадр, 0.0.6 полигональный фон LOT5, 0.0.7 PNG-фон LOT6) удалены, их можно посмотреть в истории git.

Установка на телефон: открыть `lcduitest.jad`. `MIDlet-Jar-URL` относительный, поэтому JAD и JAR
должны лежать в одной папке.
Пересборка: `./build.sh` в корне репозитория.
