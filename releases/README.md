# Releases

Собранные MIDlet-сьюты, закоммиченные вручную (`deployed/` игнорируется git).

| Версия | Что внутри | Файлы |
|--------|------------|-------|
| lotus-0.0.10 | Lotus LOT7, то же видео, что и 0.0.9 (окружение — сетка 48×64, два треугольника на клетку, 16 цветов; люди — мелкие треугольники до 4 px по ручной разметке, 64 цвета; экран 240×320; MIDI на фоне). Классы препроверены CLDC-препроверщиком (`tools/fetch_j2me_tools.sh`), декодер проверен на CLDC KVM (`tools/kvm/check_film.sh`) | `lotus-0.0.10/lcduitest.jar`, `lotus-0.0.10/lcduitest.jad` |

Предыдущие сборки (0.0.2 туннель, 0.0.3 сетка с полями, 0.0.4 статичная треугольная сетка, 0.0.5 квадродерево на весь кадр, 0.0.6 полигональный фон LOT5, 0.0.7 PNG-фон LOT6, 0.0.8 сетка 30×40 LOT7, 0.0.9 сетка 48×64 без препроверки) удалены, их можно посмотреть в истории git.

Установка на телефон: открыть `lcduitest.jad`. `MIDlet-Jar-URL` относительный, поэтому JAD и JAR
должны лежать в одной папке.
Пересборка: `./build.sh` в корне репозитория.
