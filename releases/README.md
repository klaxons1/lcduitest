# Releases

Собранные MIDlet-сьюты, закоммиченные вручную (`deployed/` игнорируется git).

| Версия | Что внутри | Файлы |
|--------|------------|-------|
| lotus-0.0.7 | Lotus LOT6: фон каждого кадра — картинка (PNG 240×320, 16 цветов), люди — полигоны (квадродерево по ручной разметке, диагонали по деталям), весь экран, MIDI на фоне | `lotus-0.0.7/lcduitest.jar`, `lotus-0.0.7/lcduitest.jad` |

Предыдущие сборки (0.0.2 туннель, 0.0.3 сетка с полями, 0.0.4 статичная треугольная сетка, 0.0.5 квадродерево на весь кадр, 0.0.6 полигональный фон LOT5) удалены, их можно посмотреть в истории git.

Установка на телефон: открыть `lcduitest.jad`. `MIDlet-Jar-URL` относительный, поэтому JAD и JAR
должны лежать в одной папке.
Пересборка: `./build.sh` в корне репозитория.
