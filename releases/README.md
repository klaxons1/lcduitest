# Releases

Собранные MIDlet-сьюты, закоммиченные вручную (`deployed/` игнорируется git).

| Версия | Что внутри | Файлы |
|--------|------------|-------|
| lotus-0.0.6 | Lotus LOT5: окружение крупными плоскими треугольниками (статичная сетка 5×6, цвет по кадру), люди мелкими треугольниками по ручной разметке (квадродерево по контурам, диагонали по деталям), весь экран 240×320, MIDI на фоне | `lotus-0.0.6/lcduitest.jar`, `lotus-0.0.6/lcduitest.jad` |

Предыдущие сборки (0.0.2 туннель, 0.0.3 сетка с полями, 0.0.4 статичная треугольная сетка, 0.0.5 квадродерево на весь кадр) удалены, их можно посмотреть в истории git.

Установка на телефон: открыть `lcduitest.jad`. `MIDlet-Jar-URL` относительный, поэтому JAD и JAR
должны лежать в одной папке.
Пересборка: `./build.sh` в корне репозитория.
