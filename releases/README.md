# Releases

Собранные MIDlet-сьюты, закоммиченные вручную (`deployed/` игнорируется git).

| Версия | Что внутри | Файлы |
|--------|------------|-------|
| lotus-0.0.14 | Lotus LOT8, то же видео (палитра на кадр, гистерезис 8, дельта палитры; люди — площадные веса). Новое: звук фильма — AMR-NB 12.2 kbps, 8 kHz mono, 160 с (`res/film-soundtrack.amr`), синхронизирован с кадрами (часы фильма идут по позиции плеера); клавиша Sound переключает фильм / MIDI / без звука. Фон MIDI с текстовыми комментариями, воспроизведение не изменилось. Джар 1 835 421 байт. Классы препроверены (`tools/fetch_j2me_tools.sh`). Не проверено на устройстве и в эмуляторе с MMAPI | `lotus-0.0.14/lcduitest.jar`, `lotus-0.0.14/lcduitest.jad` |

Предыдущие сборки (0.0.2 туннель, 0.0.3 сетка с полями, 0.0.4 статичная треугольная сетка, 0.0.5 квадродерево на весь кадр, 0.0.6 полигональный фон LOT5, 0.0.7 PNG-фон LOT6, 0.0.8 сетка 30×40 LOT7, 0.0.9 сетка 48×64 без препроверки, 0.0.10 препроверенная сборка с median cut, 0.0.11 k-means без гистерезиса, 0.0.12 LOT7, 0.0.13 LOT8 без звука) удалены, их можно посмотреть в истории git.

Установка на телефон: открыть `lcduitest.jad`. `MIDlet-Jar-URL` относительный, поэтому JAD и JAR
должны лежать в одной папке.
Пересборка: `./build.sh` в корне репозитория.
